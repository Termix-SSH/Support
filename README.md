## Where to open an issue

| What it's about | Where to open it |
| --- | --- |
| Termix itself: login, users, hosts, credentials, sharing, sync, settings, the web and desktop app | [Termix-SSH/Termix](https://github.com/Termix-SSH/Termix/issues/new/choose) |
| A plugin: terminal, file manager, Docker, remote desktop, tunnels, metrics, SSO and so on | That plugin's `Plugin-<Name>` repo. Every official plugin is listed in the [Termix README](https://github.com/Termix-SSH/Termix#plugins) |
| The iOS or Android app | [Termix-SSH/Mobile](https://github.com/Termix-SSH/Mobile/issues/new/choose) |
| The command line tool | [Termix-SSH/CLI](https://github.com/Termix-SSH/CLI/issues/new/choose) |
| The docs site | [Termix-SSH/Docs](https://github.com/Termix-SSH/Docs/issues/new/choose) |

Not sure where it goes? Open it on [Termix-SSH/Termix](https://github.com/Termix-SSH/Termix/issues/new/choose) and it will be moved to the right repo. The quickest way to report a plugin bug is **Report an issue** on the plugin's page in the Termix Plugins tab, which fills in your versions for you.

See [getting help](https://github.com/Termix-SSH/.github/blob/main/SUPPORT.md) for what to include, and the [docs](https://docs.termix.site/). For questions, join the [Discord](https://discord.gg/jVQGdvHDrf) server.
